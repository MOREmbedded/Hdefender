Chapter I

Inside the model: one token at a time

A modern LLM is a transformer. It reads text as a sequence of tokens (word pieces), and its only job is to predict the next token. Everything it seems to "know" is stored in the numbers it uses to make that prediction.

Each token is turned into a long vector, a list of thousands of numbers. That vector travels upward through dozens of identical layers. Researchers call this travelling vector the residual stream: every layer reads from it and adds a correction back into it.

step 1

Tokenize

"unbelievable" → un · believ · able. A vocabulary of 32k–200k pieces.

step 2

Embed

Each token ID looks up a learned vector of size d_model (e.g. 4096).

step 3 · per layer

Attention

Tokens look back at earlier tokens and copy in what is relevant.

step 4 · per layer

MLP

Each token's vector passes through a wide two-layer network. Much of the stored "knowledge" lives here.

step 5

Unembed

The final vector is scored against every vocabulary entry.

step 6

Sample

Softmax turns scores into probabilities; one token is picked and appended.

Steps 3 and 4 (violet) repeat once per layer: 32 times in a 7B model, 126 times in Llama 3.1 405B.

Attention computes, for every pair of tokens, how relevant the earlier one is to the later one (a dot product between a query and a key vector), normalises those scores to sum to 1, and mixes in the earlier tokens' value vectors by those weights. Tokens to the right are masked: the model may never peek at the future it is trying to predict.

A model has many heads per layer (32 in Llama 2 7B), and each learns its own habit. Some do bookkeeping, like the previous-token head. Some resolve what "it" refers to. Pairs of heads together form induction circuits that spot "A B … A" and predict "B", which is a large part of how models learn from examples in the prompt.

Chapter II

What a "parameter" is, and where they all live

A parameter is one learned number: one entry in one weight matrix. It plays the role of a connection strength, closer to a synapse than to a neuron. "7B" means seven billion such numbers. Almost all of them sit in a few matrices repeated in every layer.

Chapter III

Correlations between cells: neurons, features, superposition

If you record a single "neuron" in an LLM (one number in an MLP's hidden layer) you usually find it fires for several unrelated things: Korean text, and HTTP headers, and legal citations. It is polysemantic.

The leading explanation is superposition. A model wants to represent far more concepts than it has neurons, so it stores each concept as a direction spread across many neurons, and lets those directions overlap slightly. Concepts that rarely appear together can share neurons with little interference. The correlations between neurons are the shadows of these shared directions.

Tools called sparse autoencoders undo this. They learn a much larger dictionary of directions (millions, for production models) such that each input activates only a few. Those directions are often clean, single concepts, called features. Anthropic's 2024 work on Claude 3 Sonnet found features for the Golden Gate Bridge, code bugs, deception and inner conflict, and showed that turning a feature up changes the model's behaviour.

The brain shows the same pattern. Neurons in prefrontal cortex show mixed selectivity: one cell responds to combinations of task, stimulus and reward. Concepts appear to be carried by population codes, patterns across many cells, rather than by a single "grandmother cell". That is one of the more solid parallels between the two systems.

Chapter IV

How learning happens on each side

A network learns by gradient descent. It makes a prediction, measures the error with a loss function, and backpropagation works out, for every single weight, which direction would have reduced the error. Every weight then moves a tiny step that way. Repeat a few trillion times.

Below is that exact process running live in your browser on a tiny network: 2 inputs, a hidden layer, 1 output, learning to separate two interleaved classes (the XOR pattern). No single straight line can split them, so the hidden units must learn to cooperate.

The brain does not appear to run backpropagation as such. Its learning is mostly local: a synapse strengthens when the cells on both sides fire together (Hebb's rule, 1949), with the exact timing deciding whether it grows or shrinks (spike-timing-dependent plasticity). Global signals like dopamine broadcast "that was better than expected", which is strikingly close to the reward-prediction error in reinforcement learning. Whether the cortex approximates gradients in some other way (predictive coding, dendritic error signals) is an open research question.

Where the analogy holds, and where it breaks

synapse ↔ weight
Holds well

Both store learning as connection strengths. Neither stores a fact in one place; knowledge is distributed.

population code ↔ feature direction
Holds well

Both represent concepts as patterns across many units, and both reuse units for several concepts.

dopamine error ↔ RL reward signal
Holds well

The reward-prediction-error theory of dopamine came from machine learning and fits recordings from monkeys closely.

attention (cognitive) ↔ attention (transformer)
Partly

Same word, loosely similar job: routing information selectively. The mechanisms are unrelated.

neuron ↔ artificial neuron
Weak

A single cortical neuron, with its dendrites, behaves like a small multi-layer network of its own. An artificial unit is one sum and one nonlinearity.

lifelong learning ↔ pre-training
Weak

You learn from a single experience and keep learning. A model learns once from vast data, then stops.

Chapter VI

Connecting a brain to a computer

A brain–computer interface (BCI) records neural activity, decodes it into intent, and drives a device. The decoder is itself a machine-learning model, increasingly the same kind of model as above: speech BCIs feed decoded sound units into a language model to fix errors. So the two halves of this notebook meet here.

The core trade-off is closeness vs. risk. The nearer the electrodes sit to neurons, the clearer the signal and the more invasive the surgery.

What integration could mean next

Restoring is happening now: speech, typing, cursor and robotic-arm control for people with paralysis or ALS. Writing into the brain also exists in narrow forms: cochlear implants (over a million users), deep-brain stimulation for Parkinson's, and early visual-cortex prostheses that produce dots of light.

Augmenting healthy people, for example querying an LLM by thought, faces hard limits. Recording a few thousand neurons out of 86 billion is a keyhole. Implants degrade as the brain forms scar tissue. And every surgery carries risk. Non-invasive decoding is improving fast with AI, which also raises neural privacy questions; Chile amended its constitution in 2021 to protect "neurorights", and Colorado and California added brain data to their privacy laws in 2024.

Chapter VII

Defending both sides: infection, damage and cascades

Can a human virus affect an artificial network?

Not directly. A biological virus is a strand of DNA or RNA that needs a living cell's machinery to copy itself. A GPU has no ribosomes, membranes or receptors, so there is nothing for it to infect. The paths that do exist are indirect:

Through the person. Illness, fever, medication or inflammation change the neural signals a BCI reads, so the decoder's accuracy drops. Implants must be recalibrated, and an infection at the implant site is a real surgical risk. Through its digital cousins. The true analogue of a virus for AI is malicious code and malicious data, covered below. Those can spread, and they can spread between AI systems.

Can connections inside a model be destroyed?

Yes. Weights are numbers in memory, and memory can be changed by hardware faults, by attackers or by a corrupted file. How bad it is depends on which numbers are hit:

Most weights are redundant. You can delete (prune) a large share of a network's connections, often half or more, and lose little accuracy. Training with dropout deliberately knocks out random units so the network learns not to depend on any one of them. That works much like the brain's tolerance to the loss of individual neurons.

A few weights are critical. In 2019, the "Terminal Brain Damage" study showed that flipping a single bit in the exponent of one weight (via a Rowhammer memory attack) can collapse an image classifier. In 2024, researchers found "super weights" in LLMs: zeroing one specific scalar in Llama‑7B turns its text into gibberish. Damage is not uniform. The brain has the same kind of weak points, such as the small brainstem regions that keep you conscious.

So does damage propagate further?

There are two different things that can spread, and the answer differs for each.

During use (inference), corrupted activity spreads, but corrupted weights do not. A damaged connection in layer 1 changes what layer 1 outputs, and every later layer works on that changed output. Whether the error grows or fades depends on the network's regime, as the experiment shows. When connections are weak (gain below 1), disturbances fade. When they are strong (gain above 1), the network is chaotic and a tiny change grows until the output is unrelated to the original. Real LLMs are built near the boundary, using residual connections and normalization layers that keep signals from exploding or dying out. The weights in other layers are not touched. The damage is recomputed on each pass, but it does not copy itself into healthy weights.

During training, corruption can spread to every weight. One bad value, such as a NaN or an overflow, flows into the loss, and backpropagation sends it to every parameter in one step. A whole model can be ruined in a single update. This is a true avalanche, and it is why training runs use gradient clipping, loss-spike detection and frequent checkpoints to roll back to.

The brain has the same dichotomy. Cortex appears to operate near a critical point. Spontaneous activity comes in neuronal avalanches (Beggs and Plenz, 2003) whose sizes follow a power law, the signature of a system balanced between dying out and running away. When inhibition fails, activity tips into the runaway regime: an epileptic seizure is exactly that, a cascade spreading from a focus across healthy tissue. After a stroke, dying neurons release glutamate that overexcites and kills their neighbours (excitotoxicity), so physical damage also spreads. Inhibitory neurons play the role normalization plays in a transformer.

Can an AI brain get a degenerative disease?

First, an important fact. A deployed LLM does not learn from your conversation. Its weights are frozen; a chat changes only the temporary context, which is gone when the chat ends. So one user cannot reach in and rewire the model while it is running. Degradation enters at the moments when weights do change: pre-training on new data, fine-tuning, and training on user feedback for the next version. At those moments it is very real, and several conditions mirror human brain diseases closely.

Real simulation: each generation learns word frequencies from 300 words of the previous generation's output

Rare words are the first to go. Once a generation fails to produce a word even once, the next generation assigns it zero probability and it can never come back. This is the "prion" mechanism: corrupted output becomes the input that produces more corrupted output. Raise the fresh-data slider and the lost words return. That is the defence used in practice: keep training anchored to real, verified human data.

Defence principles that work on both sides

Redundancy. Spread function over many units so no single loss is fatal (dropout, distributed codes, bilateral brain areas). Damping. Keep the system near, not past, the critical point (normalization layers, inhibitory neurons). Integrity checks. Know when something changed (hashes, checksums, monitoring; the brain's equivalent is immune surveillance). Isolation. Limit how far a failure can reach (sandboxed agents, the blood–brain barrier). Recovery. Keep a known-good state to return to (checkpoints; in the brain, plasticity and rehabilitation).
